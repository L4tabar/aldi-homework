## Task-1: Test Design and Bug Report

Based on the accepted changes regarding the task-1, the test cases will not follow the examples mentioned in the task
description.
Instead, the test cases will be created against the https://demowebshop.tricentis.com/ website (which will be used in
task-2 as well).
The test design will be created based on the following scenarios:

1. Adding a virtual gift card to the shopping list from the "FEATURED PRODUCTS" list
2. Adding multiple products to the shopping list from the "FEATURED PRODUCTS" list
3. Adding a virtual gift card without filling the required fields

Please keep in mind that the test cases might not include some checks, etc. because of the missing requirements and
because it is a demo website.

The tests can be found here: [AddToCart.md](TestDesign/AddToCart.md)
